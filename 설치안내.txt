====================================================
 monoshorts — Premiere Pro 세로 쇼츠 변환 패널 (macOS)
====================================================

■ 설치 (처음 한 번)
  1. 터미널을 엽니다 (Spotlight에서 "터미널")
  2. bash 라고 입력하고 한 칸 띄운 뒤, install-mac.command 파일을 터미널 창으로 끌어다 놓고 Enter
  3. 프리미어를 완전히 종료(⌘Q)했다가 다시 켭니다
  4. 상단 메뉴 → 창(Window) → 확장명(Extensions) → monoshorts
  ※ 이미 설치돼 있어도 그대로 덮어쓰며, 내 설정(하단 이미지·저장 폴더 등)은 유지됩니다.

■ 사용 방법
  1. 가로 시퀀스에서 In(I)/Out(O)으로 구간을 잡고 "＋ 이 구간 담기" (여러 번 가능)
  2. "담은 구간으로 쇼츠 만들기" → [쇼츠] Short N 시퀀스가 생깁니다
  3. 익스포트 탭에서 하단 이미지 적용 · 파일 출력

■ 자막 줄바꿈 (1.0.4~)
  - 쇼츠를 만들 때 화면 밖으로 넘치는 자막을 자동으로 두 줄로 나눕니다
    (설정 탭 → 자막 줄바꿈 → "쇼츠 만들 때 자동으로 줄바꿈")
  - 이미 만든 쇼츠: 자막이 든 ~reframe 시퀀스를 열고 "열린 시퀀스 전체"
  - 자막 하나만 시험: 타임라인에서 자막 클립 선택 → "선택한 자막만 (테스트)"
  - 마음에 안 들면 "마지막 줄바꿈 되돌리기" (여러 번 누르면 차례로 되돌림)
  - 너무 일찍/늦게 끊기면 "화면 폭 사용 %"를 조절하거나 "한 줄 최대 글자 수"를 지정

■ 업데이트 / 이전 버전으로 되돌리기
  - 패널을 열 때 GitHub(kimnemo13/monoshorts)에서 새 버전을 자동으로 받습니다
  - 설정 탭 → 업데이트 · 버전 → "다른 버전"에서 옛 버전을 골라 "이 버전 설치"
    → 옛 버전을 설치하면 자동 업데이트가 멈춤(버전 고정). 최신을 다시 설치하면 다시 켜짐
  - 패널이 아예 안 열리면: GitHub 저장소에서 release-버전 브랜치를 골라 ZIP으로 받아
    install-mac.command로 설치

■ 제거
  - 터미널에서: bash uninstall-mac.command

■ 개인정보
  - 사용 통계·데이터 전송 없음. 업데이트 확인을 위해 GitHub에만 접속합니다.
