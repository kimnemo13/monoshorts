# monoshorts

Premiere Pro에서 가로 영상의 구간을 골라 **세로 쇼츠(1080×1920)** 로 자동 변환하는 패널입니다. (macOS)

## 설치
1. 이 저장소를 내려받습니다. (Code → Download ZIP → 압축 풀기)
2. 터미널에 `bash ` 를 입력하고, `install-mac.command` 파일을 터미널 창으로 끌어다 놓은 뒤 Enter
3. 프리미어를 완전히 종료(⌘Q)했다가 다시 켜고 → 창 > 확장명 > **monoshorts**

설치 후에는 패널을 열 때마다 GitHub에서 새 버전을 확인해 **자동으로 업데이트**합니다.

## 이전 버전으로 되돌리기
- 패널 **설정 탭 → 업데이트 · 버전 → 다른 버전**에서 원하는 버전을 고르고 **이 버전 설치**.
- 옛 버전을 설치하면 "버전 고정"이 걸려 자동 업데이트가 멈춥니다. 최신 버전을 다시 설치하면 자동 업데이트가 다시 켜집니다.
- GitHub 저장소의 브랜치 목록(release-1.0.3, release-1.0.4 …)에서 해당 버전을 골라 Code → Download ZIP으로 받아 `install-mac.command`로 설치해도 됩니다.

## 버전 기록
| 버전 | 내용 |
|---|---|
| 1.0.7 | 자막 줄바꿈을 익스포트 탭으로 이동 — 작업 중인 것에 적용 / 전체 적용 (쇼츠 만들 때 자동 줄바꿈은 끔) |
| 1.0.6 | 쇼츠 만들 때 자동 줄바꿈 결과(몇 개·못 찾은 이유)를 패널에 표시 |
| 1.0.5 | 자막 텍스트 인식 개선(속성 이름 대신 값으로 판별), 못 찾을 때 진단 표시 |
| 1.0.4 | 화면 밖으로 넘치는 자막 자동 줄바꿈(쇼츠 만들 때 자동 / 버튼으로 수동 / 되돌리기), GitHub 자동 업데이트·버전 선택 |
| 1.0.3 | 기존 기능 (+ 업데이트·버전 선택 기능만 추가) |

## 개인정보
사용 통계나 데이터를 보내지 않습니다. 업데이트 확인을 위해 GitHub에만 접속합니다.

※ 실제 버전은 `version.json` 기준입니다. (`CSXS/manifest.xml`의 버전은 프리미어 재시작이 필요 없도록 고정해 둠)
